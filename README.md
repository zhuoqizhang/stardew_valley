# MyFirstMod — 星露谷期货交易系统

一个给《星露谷物语》皮埃尔商店添加"期货交易"玩法的 SMAPI Mod。玩家可以预先签约，
在未来某个交割日以约定价格交割啤酒或淡啤酒；价格会围绕游戏原生售价动态浮动，
到期不交割则违约、没收保证金并支付差价罚金。

## 功能特性

- **远期合约签约与交割**：选定物品、约定价格、到期日，到期当天找皮埃尔交割
- **FIFO 交割队列**：同一物品多张合约按签约时间严格排队，不可插队
- **动态定价引擎**：价格围绕游戏原生售价做多层次模拟波动——均值回归、日常噪声、
  周几周期、节日需求脉冲、随机市场冲击、季节性偏移，以及围绕两大节日
  （秋季集市、盛宴节）的月度级长趋势，啤酒与淡啤酒价格联动但幅度不同
- **违约结算**：到期未交割自动判违约，没收保证金 + 按市场价与约定价差额收取罚金，
  次日发送违约通知信
- **真正的远程联机支持**：Host 权威同步架构，任意在线玩家可以交割任意人签订的合约，
  资金/合约/价格数据在所有客户端间保持一致
- **中英文双语支持**：跟随游戏语言设置自动切换界面文字

## 安装

详见 [INSTALL.md](INSTALL.md)——包含完整的分步安装指南，也适合直接丢给 AI 助手引导安装。

**多人游戏用户请特别注意**：房间里所有玩家都必须安装本 Mod，不只是房主。

## 系统要求

- 《星露谷物语》1.6 及以上版本
- [SMAPI](https://smapi.io/) 最新版

## 已知限制

- 折线图/K线图等价格走势可视化尚未实现（价格历史数据已在记录，UI 待开发）
- 提前平仓/卖出期货功能尚未实现
- 部分违约（整单交割其中一部分）不支持，当前为整单判定
- 出货箱自动交割拦截未实现（需手动通过背包点击交割）
